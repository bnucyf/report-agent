# 智能报表机器人 - 用户使用手册

## 开始使用

### 单聊

1. 在钉钉搜索「智能报表」机器人
2. 点击 **发消息** 进入单聊
3. 直接发送关键词，机器人会返回分析数据

### 群聊

1. 把机器人添加到群（群设置 → 智能群助手 → 添加）
2. 在群中 `@智能报表` + 关键词触发

## 功能详解

### 1. 数据库总览

发送「概览」或「总览」，机器人返回：
- 数据库表总数
- 业务候选表数
- 质量问题数
- 生产用料行数
- 字段总数
- 业务表模块分布
- 数据量 Top 10 表

### 2. 生产用料分析

发送「生产用料」，机器人返回：
- **KPI 总览**：加工单数、产品种类、材料种类、明细行数
- **产品加工排行 Top 10**：按加工单数排序
- **材料使用排行 Top 10**：按使用频次排序
- **用料明细**：前 10 行数据

### 3. 数据质量诊断

发送「质量」，机器人返回：
- **质量总览**：问题记录数、涉及表/字段、问题总数
- **问题类型分布**：空值 / 空字符串 / 异常日期 / 负数值
- **问题集中表 Top 15**：质量问题最多的表

发送「空值」可专项查看字段完整性问题。
发送「异常」或「负数」可专项查看异常值。

### 4. 字段资产盘点

发送「字段」，机器人返回：
- **字段资产总览**：表总数、字段总数、时间/金额/数量字段数
- **模块分布**：各业务模块的表数量
- **字段类型分布**：字段数据类型分类
- **大表排行 Top 15**：数据量最大的表

### 5. 数据库扫描

发送「扫描」启动数据库扫描。扫描过程：
1. 扫描所有表结构（表/列/索引）
2. 分类业务候选表（约 480 张）
3. 逐表抽样检查数据质量（空值/异常/负数）
4. 自动生成所有报表快照

扫描约需 10-60 分钟（取决于 `DB_SAMPLE_ROWS` 配置），完成后自动生成：
- `quality_issues_*.csv` — 质量问题明细
- `production_material_usage_*.csv` — 生产用料明细
- `field_inventory_*.csv` — 字段资产清单
- `smart-report-demo_*.html` — 完整分析报告

发送「进度」可随时查看扫描状态。
发送「重扫」可清空进度重新全量扫描。

### 6. 报告推送

发送「报告」，机器人会：
1. 生成 PDF 版完整分析报告（需要 Edge/Chrome 浏览器）
2. 生成 Excel 版生产用料明细
3. 上传到钉钉聊天文件
4. 返回通知消息

## 定时推送

在 `config/scheduler.yaml` 中配置后，机器人会按计划自动推送：

| 场景 | 默认配置 |
|------|---------|
| 每日生产用料速览 | 工作日早 8 点推送到群 |
| 每周质量周报 | 周一早 9 点推送到群 |
| 月度字段资产 | 每月 1 日凌晨 2 点推送到群 |
| 每周自动重扫 | 周日凌晨 2 点自动扫描 |
| 每日数据总览 | 工作日早 8 点推送到管理员单聊 |

修改 `scheduler.yaml` 中的 `chat_id` 为你的群 ID 即可启用。

## 常见问题

### Q: 第一次使用应该先做什么？
A: 先发送「扫描」启动数据库扫描，等扫描完成后再查询数据。

### Q: 数据多久更新一次？
A: 每次扫描后数据更新。可以手动发送「重扫」，或配置定时任务自动重扫。

### Q: 群聊中怎么触发机器人？
A: 在消息中 `@智能报表` + 关键词，如 `@智能报表 生产用料`。

### Q: 报告文件在哪查看？
A: 机器人发送报告后，文件会出现在钉钉聊天窗口的文件列表中，可直接下载。

### Q: 数据安全吗？
A: 所有数据在用户本地处理，不经过任何第三方服务器。钉钉仅用于消息传输，不存储数据库内容。
