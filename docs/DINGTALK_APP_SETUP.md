# 钉钉应用配置指南

## 1. 登录开发者后台

访问 [https://open-dev.dingtalk.com](https://open-dev.dingtalk.com)，用钉钉扫码登录。

## 2. 创建企业内部应用

1. 左侧菜单 → **应用开发** → **企业内部应用** → **创建应用**
2. 填写应用信息：
   - **应用名称**：智能报表（或自定义名称）
   - **应用图标**：上传一个图标（可选，可用默认）
   - **应用描述**：数据库分析机器人，支持在钉钉中查询生产用料、数据质量、字段资产等
   - **应用首页地址**：可填本地 Streamlit 地址 `http://localhost:8501`（可选）
3. 点击 **创建**

## 3. 开启机器人能力

1. 进入应用详情 → **应用能力** → **机器人**
2. 点击 **开启**
3. 机器人配置：
   - **机器人名称**：智能报表
   - **消息接收模式**：⚠️ **必须选 Stream 模式**
   - **机器人描述**：数据库分析助手
4. 保存

> **为什么选 Stream 模式？**
> - 不需要公网 IP / 域名 / HTTPS 证书
> - 不需要内网穿透
> - Python SDK 官方维护，开箱即用
> - 一个 WebSocket 连接同时处理文本消息和卡片回调

## 4. 申请权限

进入 **权限管理** → 搜索并申请以下权限：

| 权限名称 | 权限标识 | 用途 |
|---------|---------|------|
| 企业内机器人发送消息 | `qyapi_robot_sendmsg` | 机器人回复用户消息 |
| 互动卡片实例读 | - | 读取互动卡片数据 |
| 互动卡片实例写 | - | 创建/更新互动卡片 |
| 文件上传 | - | 上传 PDF/Excel 报告 |
| 通讯录只读 | - | 获取用户信息（可选） |

> 部分权限可能需要管理员审批，请提前申请。

## 5. 获取凭证

进入 **基础信息** 页面，记下以下 4 个值：

| 凭证 | 在 .env 中的变量名 | 说明 |
|------|-------------------|------|
| AppKey | `DINGTALK_CLIENT_ID` | 应用唯一标识 |
| AppSecret | `DINGTALK_CLIENT_SECRET` | 应用密钥（⚠️ 不要泄露） |
| AgentId | `DINGTALK_AGENT_ID` | 应用代理 ID |
| CorpId | `DINGTALK_CORP_ID` | 企业 ID（在「我的企业」页面查看） |

## 6. 配置应用可见范围

1. 进入 **应用发布** → **版本管理与发布**
2. 选择 **本企业发布**
3. 设置可见范围（选择需要使用的部门/人员）
4. 提交发布 → 等待企业管理员审批

## 7. 验证

1. 在钉钉客户端搜索机器人名称
2. 发起单聊，发送「帮助」
3. 如果收到使用说明，表示配置成功

## 8. 获取群 chat_id（定时任务用）

如果需要定时推送到群：
1. 在钉钉创建一个群（或使用现有群）
2. 把机器人添加到群中（群设置 → 智能群助手 → 添加机器人 → 选择企业内部应用）
3. 在群中 @机器人 发送任意消息
4. 查看 `outputs/bot.log`，找到 `conversationId` 字段
5. 将该值填入 `config/scheduler.yaml` 的 `chat_id`

## 常见问题

### Q: Stream 模式和 HTTP 模式有什么区别？
A: Stream 模式通过 WebSocket 长连接接收消息，不需要公网 IP；HTTP 模式需要配置公网 HTTPS 回调地址。本项目推荐使用 Stream 模式。

### Q: 应用发布后多久生效？
A: 审批通过后立即生效，通常几分钟内。

### Q: 如何修改机器人名称？
A: 在开发者后台 → 应用详情 → 机器人 → 修改机器人名称，保存后重新发布版本。

### Q: 多个群能用同一个机器人吗？
A: 可以。把机器人添加到不同群，每个群有独立的 conversationId。
